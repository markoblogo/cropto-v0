# Cropto — що це і навіщо

**Cropto** — простий, прозорий інструмент для управління ціновими ризиками на агроринку. Ми з’єднуємо фізичний ринок зерна і цифрові інструменти (NFT та токен CROPT), щоб фермери могли хеджувати ціни, а трейдери отримували додатковий дохід.

## Для кого
- **Фермери** — захистити виручку, зафіксувавши ціну на майбутню партію.
- **Трейдери** — отримувати премії за продаж опціонів і заробляти на ринкових рухах.
- **Брокери / оператори** — організовувати угоди і вести реєстри, які синхронізуються з фізичною поставкою.

## Як це працює (коротко)
1. Створюється фізична угода (фермер ↔ трейдер) або продаж опціону.
2. В системі випускається **NFT-опціон** (CALL/PUT) з параметрами: страйк, об’єм, строк, премія.
3. Щоденний перерахунок за Spike Spot Commodity Index — PnL, margin-call, payout.
4. Розрахунки спочатку off-chain, потім опційно — withdraw → mint on-chain (CROPT).
5. Адмінпанель: реєстр партнерів, журнал транзакцій, reconciliation.

## Що містить NFT-опціон
- id опціону та прив’язка до фізичного контракту
- тип (CALL/PUT), страйк, об’єм (тонни), строк дії
- премія та валюта розрахунків (CROPT / фіат)
- статус виконання / виплати

## Потік коштів (спрощено)
- Премія — продавцю (трейдеру) або як дисконт у фізичному контракті.
- При exercise — payout з collateral або CROPT-балансу.
- CROPT можна обміняти на stablecoin/вивести через звичні канали.

## Навіщо це корисно
- Фермерам — простіший інструмент хеджування.
- Трейдерам — нові джерела доходу.
- Ринку — прозорий журнал і простіший старт пілотів.
