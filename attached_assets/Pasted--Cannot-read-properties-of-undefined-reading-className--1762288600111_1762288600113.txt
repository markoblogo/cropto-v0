Отлично — видно, где упало. Ошибка Cannot read properties of undefined (reading 'className') означает, что в StatusBadge.tsx переменная variant (или объект variant) равна undefined, а код пытается взять variant.className. Быстро и безопасно фиксится добавлением дефолтного варианта и защитой от undefined, плюс — полезной диагностикой в лог, чтобы сразу видеть, какие статусы прилетают.

Ниже — готовый патч (TSX) — можно вставить прямо в client/src/components/StatusBadge.tsx. Он:
	•	подстраховывает status (работает с undefined/null/маленькими буквами),
	•	имеет таблицу STATUS_VARIANTS (можно дополнять под ваши цвета/классы),
	•	подставляет DEFAULT_VARIANT, если маппинга нет,
	•	логирует в консоль незнакомые статусы (можно убрать позже).

Замените содержимое client/src/components/StatusBadge.tsx на это:

import React from "react";
// импорт вашего Badge — оставьте актуальный путь к UI компоненту
import { Badge } from "@/components/ui/badge"; // <-- поправьте, если у вас другой путь

type Variant = {
  className: string;
  label?: string;
};

const STATUS_VARIANTS: Record<string, Variant> = {
  OPEN: { className: "bg-olive-600 text-white" },
  MARGIN_CALL: { className: "bg-yellow-600 text-white" },
  DEFAULTED: { className: "bg-red-600 text-white" },
  CLOSED: { className: "bg-gray-600 text-white" },
  PENDING: { className: "bg-indigo-600 text-white" },
  // добавьте другие статусы по нужде...
};

const DEFAULT_VARIANT: Variant = { className: "bg-gray-200 text-gray-800" };

export interface StatusBadgeProps {
  status?: string | null;
  className?: string;
}

export default function StatusBadge({ status, className = "" }: StatusBadgeProps) {
  // безопасно нормализуем статус
  const normStatus = (typeof status === "string" && status.trim()) ? status.trim().toUpperCase() : "UNKNOWN";

  // получаем вариант из маппинга, если нет — дефолт
  const variant: Variant = STATUS_VARIANTS[normStatus] ?? DEFAULT_VARIANT;

  // для отладки: логируем неожиданные статусы один раз
  if (normStatus === "UNKNOWN" || !STATUS_VARIANTS[normStatus]) {
    // eslint-disable-next-line no-console
    console.warn(`[StatusBadge] unknown status "${status}" -> using DEFAULT_VARIANT`);
  }

  return (
    <Badge
      variant="outline"
      className={`${variant.className} uppercase text-xs font-semibold tracking-wider ${className}`}
      data-testid={`badge-status-${normStatus.toLowerCase()}`}
    >
      {variant.label ?? normStatus.replace(/_/g, " ")}
    </Badge>
  );
}

Примечание:
	•	Путь импорта Badge (@/components/ui/badge) может отличаться в вашем проекте — замените на актуальный.
	•	CSS-классы (bg-olive-600, text-white и т.д.) — пример. Подставьте те классы/цвета, что у вас используются (Tailwind/другой дизайн-система). Главное — убрать обращение к variant.className без проверки.
