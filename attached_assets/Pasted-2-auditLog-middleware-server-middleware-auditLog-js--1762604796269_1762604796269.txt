2. Добавь простой auditLog middleware:
    

  

- Создай файл server/middleware/auditLog.js:
    

```
// server/middleware/auditLog.js
module.exports = function auditLog(req, res, next) {
  try {
    const user = (req.user && req.user.id) || req.headers['x-user-id'] || 'anonymous';
    console.info(`[AUDIT] ${new Date().toISOString()} ${req.method} ${req.originalUrl} user=${user} ip=${req.ip}`);
  } catch (e) {}
  next();
};
```

3. Зарегистрируй оба middleware в сервере:
    

  

- Вставь перед всеми роутами (в начале файла server/index.js или app.js, сразу после express() и парсеров) строки:
    

```
const blockServiceRole = require('./middleware/blockServiceRole');
const auditLog = require('./middleware/auditLog');
app.use(blockServiceRole);
app.use(auditLog);
```
