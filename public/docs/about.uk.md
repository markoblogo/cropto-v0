# Про Cropto

**Cropto** — це експериментальна платформа для **хеджування цінових ризиків зерна** та торгівлі **NFT-опціонами**, які привʼязані до реальних фізичних цін через **Spike Spot Commodity Index**.

## Для кого платформа

- **Фермери** — фіксують ціну продажу майбутнього врожаю, зменшуючи ризик падіння ринку.
- **Трейдери** — продають опціони, отримують премії, керують заставою та margin call.
- **Брокери / партнери** — підключають клієнтів, ведуть реєстр угод і контролюють ризики.

## Як це працює (Pre-MVP)

1. Сторони домовляються про **фізичну угоду** офлайн (фермер ↔ трейдер або трейдер ↔ трейдер).  
2. У Cropto створюється **опціон**:
   - тип: CALL / PUT  
   - страйк (ціна)  
   - обсяг у тоннах  
   - дата експірації  
   - премія  
   - застава (маржа)
3. Опціон може бути **зіставлений (matched)** на платформі та отримує статус FILLED.
4. Після цього опціон можна **замінтити як NFT (ERC-721)** в мережі Polygon Amoy:
   - у metadata зберігаються optionId, тип, страйк, обсяг, дата, ролі сторін та посилання на контракт.
5. Щоденно опціон **переоцінюється** за індексом Spike Spot Commodity Index:
   - розраховується PnL, перевіряються пороги для margin call та можливого forced settlement.
6. В момент експірації або дострокової реалізації створюється запис **settlement** та фіксується виплата у фіаті або CROPT.

## Що містить NFT-опціон

NFT є **цифровим підтвердженням права** на розрахунок за конкретним опціоном. У metadata містяться:

- `optionId` — внутрішній ідентифікатор у базі Cropto
- тип опціону (CALL / PUT)
- страйк-ціна
- обсяг (тонни)
- дата експірації
- ролі покупця та продавця
- посилання на фізичний контракт або брокерську угоду

## Поточний статус

- Використовується тестова мережа **Polygon Amoy** та тестовий токен CROPT.  
- Усі сценарії зараз **демонстраційні**, із обмеженою кількістю реальних контрагентів.  
- Мета цього Pre-MVP — перевірити UX, логіку ризик-менеджменту та модель даних перед масштабуванням.
