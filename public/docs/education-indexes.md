### Commodity Indexes

- Cropto tracks local CPT Odesa / CPT Paritet prices as export vs processing indexes.
- Export indexes exclude VAT; processing indexes include VAT and local handling.
- Each index has a slug and pair code (e.g., CROPT/CRNEX for Corn).
- Spot tokens mirror the index price in CROPT; no physical grain moves.
- Indices drive pricing for spot, options, and risk checks.
