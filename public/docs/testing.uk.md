# Інструкція з тестування (UK)

Демо-логіни (пароль: `pass`):
- Фермер: `farmer@demo`
- Трейдер: `trader@demo`
- Брокер: `broker@demo`

## A. Тест у ролі фермера

1. Увійдіть як `farmer@demo`.  
2. Створіть новий опціон (CALL або PUT) з невеликим обсягом та зрозумілим страйком.  
3. Переконайтесь, що він зʼявився на дашборді зі статусом **OPEN**.  
4. Попросіть брокера (або зайдіть як `broker@demo`) зробити match → статус має стати **FILLED**.  
5. Якщо є тестовий POL, натисніть **Mint NFT** і перевірте токен у мережі Polygon Amoy.

## B. Тест у ролі трейдера

1. Увійдіть як `trader@demo`.  
2. Знайдіть OPEN опціони та зробіть match для одного з них.  
3. Слідкуйте за статусом маржі та PnL на сторінці Portfolio.  
4. Ініціюйте exercise через UI та перевірте, що settlement і транзакції записані.

## C. Тест у ролі брокера / адміністратора

1. Увійдіть як `broker@demo`.  
2. Використовуйте екрани адміністрування:
   - перегляд угод та розрахунків  
   - експорт CSV  
   - перевизначення індексних цін (для демо)  
3. Перевірте, що зміни відображаються на дашборді та у портфелі.

Ця інструкція призначена **лише для демонстрації** і не є інвестиційною порадою.
